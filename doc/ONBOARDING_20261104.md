# 首次启动、标定与物理时序：2026-11-04

## 操作

首次打开按顺序确认项目原始开源许可、第三方许可、模型及生成内容使用说明；不同意会退出软件。确认只保存到当前用户的 Onboarding.json，绑定实际展示的许可文本摘要。许可变化后重新确认，已完成的新手引导保持完成状态。此确认不修改 MIT 权利或替用户授予第三方素材使用权。

确认后显示一次拖入模型 ZIP 的引导，可直接拖放或选择文件。选择 PMX 后显示压缩包中的使用说明，阅读面板在前台可见至少 5 秒并勾选确认，才能继续加载；取消保留当前模型。H、Esc、底层菜单、拖入另一包或视角操作不能跳过面板。UTF-8、UTF-16 和常见 GBK 文本可直接阅读，其他说明文件和未识别/过长文本需打开原目录检查。未找到说明不代表模型可自由使用。不执行说明中的指令，也不自动打开其外部链接。

右上角显示渲染帧率和识别帧率；摄像头停止或识别结果过期时显示 0。渲染值由实际游戏循环间隔平滑统计，不是 GPU 工作耗时；固定步进回放中它会反映测试指定的游戏时钟。

标定向导用稳定动作的中位数计算满值，再向放松阈值内收约 10%；保留放松态抗噪死区、最低有效范围、稳定性和真实帧数检查。已有配置不自动改写，重新运行向导后应用新提案。
