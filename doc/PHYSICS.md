# PMX 物理

本文从仓库根目录执行命令。MMD 解析由 VRM4U/Assimp 完成，物理由固定版本的 UMT/Bullet fork 执行；不把 PMX 刚体改造成 VRM 弹簧链，也不按角色名称修补。

## 构建与依赖

初始化子模块后运行：

```powershell
./Scripts/Prepare-PmxPhysics.ps1
```

脚本复用已有 CMake、Ninja、Git、MSVC 和 Windows SDK。UMT 源码版本由宿主 gitlink 固定，Bullet 3.07 固定为 `272c7099d3ba8ac9e8c142e361e8d4cf5d91b8f2`；准备过程检查版本并运行 native 回归。可通过脚本的 `-BulletRoot` 使用已准备的匹配源码；脚本不会安装编译工具。详见[构建说明](BUILD.md)。

产物为 `Tools/UMTNativePlugin/build-static-ue144/bundled/UMTNativePlugin.lib`，不提交到 Git。VRM4U 在 Windows x64 检测到该库后启用 Bullet；缺少库时导入器仍可用，但 PMX Bullet 不可用。更换工具链后须重新构建，不能复用其他 ABI 的静态库。

## 数据与执行顺序

1. 导入器保存 PMX 原始刚体、模式、关节、质量、阻尼、限位、弹簧和碰撞组。刚体骨骼引用与导入骨骼使用相同的通用名称规范。
2. 动画代理提供完整的当前骨骼姿态，mode 0 刚体跟随动画；mode 1 接受物理；mode 2 保留动画局部位置并采用物理旋转。
3. 固定 30 Hz、每帧最多一个子步、48 次求解迭代，给重模型的物理和渲染留出时间。超出单步预算的时间不再连续追赶；机器超载时次级物理会变慢，避免长帧反复放大。子步的动画采样计入累计器相位，长帧、模型或统一缩放变化触发受控重置。原始 PMX 数据、碰撞组和弹簧参数保留；运行时采用下述网格碰撞包络、冲突锁位兼容和接触退让。
4. Mode2 回正读取同一时刻的 native 世界快照；不会把显示插值结果反馈给当前求解器。
5. 显示将动画骨骼与物理骨骼按同一组前后快照插值，统一增加约一个固定步（33.3 ms）的显示延迟，避免当前头部与上一物理步发束错位。渲染帧率不受物理更新频率限制；零步帧仍可连续显示，零时间帧保留相位，重置清除旧历史。

宿主把求解后的骨骼结果交给 UE 蒙皮，渲染插件不负责物理。没有合适刚体、关节或蒙皮权重的模型不会自动产生头发或衣物物理。

## 碰撞与关节

PMX 碰撞掩码按原始含义传入 Bullet：置位表示允许该组接触。只屏蔽关节直接连接的刚体对，其余碰撞组保持原值。无效索引、非有限数据或不支持的关节会明确拒绝初始化。

导入时从同一份绑定姿态顶点与 Assimp 骨骼权重生成碰撞表面，避免读取尚在异步初始化的渲染缓冲。主权重至少一半的顶点归入对应骨骼的最近动态刚体，按 0.5 毫米网格去重。Mode 0 身体碰撞体保留作者形状，避免不完整的网格采样缩小肩颈等部位的碰撞覆盖；初始化也忽略旧数据中的 Mode 0 表面点。动态刚体至少四点时，由 Bullet 生成凸包并重算该形状的转动惯量；质量、刚体位置、骨骼回写和组掩码保持一致。无足够表面点的刚体保留作者形状。凸包是分骨骼近似，不等同于逐三角面布料模拟，混合蒙皮、凹形表面及表情变形仍需画面回归。

类型 0 关节采用 Spring2，保留作者的平移/旋转刚度，零刚度轴仍施加相对速度阻尼；关节阻尼为 `.5`。刚体阻尼独立取自模型，在 Bullet 支持范围内限制。mode 0 为根、六轴完全锁定且不含绑定 mode 2 的焊接链，以原始关节相对框架求值；不改源 PMX 数据。

对无弹簧预载、A 端运动学/B 端动态的非零等值线性锁位，仅当同一精确焊接根的另一条约束证明其目标不可兼容时，校准运动学侧关节参考点。证明包含轴向一致性、另一约束在绑定姿态有效及动态端力臂可提供的旋转补偿上界；自由轴、合法非零目标和弹簧预载不改变。校准在构建时执行，重置不累计偏移，mode 1 仍回写完整刚体姿态，不以单独平移显示网格掩盖碰撞位置。

可动附件分支受到其他身体部位的静态/运动学碰撞体阻挡时，接触 CFM 为 0、ERP 为 `.8`；附件自身根骨骼（包括经多级完全锁定连接继承的运动学驱动骨骼）上的重叠代理、未归属此类分支的物体及动态部件之间不覆盖原有接触 CFM/ERP。接触位置纠正采用分离冲量，关节闭环仍保留 `.001` CFM 正则化。对于连接运动学根、平移锁定且旋转可动的 Spring2 分支，身体阻挡时暂时把非锁定旋转轴的允许范围扩至至少 ±60°，保留原弹簧、连接点和48次基础求解预算。每步积分后按运动学根的关节框架恢复平移锁定连接点，并使根附件的线速度与连接点速度一致，避免有限求解预算造成发根脱离。接触解除后以每秒 30° 收回放宽区间并唤醒动态根，避免零弹簧或休眠使放宽永久保留；再次接触则继续避让。完全锁定轴、自由轴及焊接件不放宽。这是避免窄角限与肩部阻挡互相冲突的通用物理取舍，不改写模型数据。

采用标准 Bullet 岛休眠与接触摩擦基底。静止 mode 0 目标不反复唤醒刚体；实际移动和重置仍唤醒。只有受关节约束、实际角阻尼至少 `.9` 的动态刚体使用 `3 rad/s` 角休眠阈值；其他刚体维持标准 `1 rad/s`。休眠是静止近似，不代表模型的限位和接触冲突已经消失。

## 验证与限制

修改桥接层时运行 `VRM4U.PMX` 自动化测试和 UMT 的 native 回归，覆盖重力、重置、碰撞组、Mode2 当前父链、子步相位、零步/零时间显示、运动头部与物理附件显示同步、受阻附件退让及恢复、休眠与真实移动唤醒。宿主测试入口见[开发说明](DEVELOPMENT.md)。

2026-11-08 肩颈覆盖回归：局部皮肤采样曾缩小原身体碰撞体，导致中立姿态发梢进入衣领。保留 Mode 0 原形状后，该复现的新增三角面交线由 118 对降为 0；`VRM4U.PMX` 14 项及 native 3 组通过。动态转头快照仍有约 1–3 像素的发梢与衣领/领结局部交线，因此该结果不代表所有动作完全无穿插。

数值稳定不能代替最终网格验收。请另外检查不同拓扑模型的蒙皮、衣物与身体接触、头转、手臂及跟踪噪声；作者设置的重叠碰撞体、冲突限位或不正确权重仍可能造成穿插和残差。不要通过按模型名硬编码、关闭所有碰撞或覆盖原始骨骼来掩盖问题。

30 Hz / 48 次是优先流畅的精度取舍：相较原 60 Hz / 80 次，快速接触的时间分辨率和约束收敛精度会降低。开发自动化构建可用 `-PmxQaHz=60 -PmxQaIterations=80` 复测旧预算；覆盖参数不会进入 Shipping。
