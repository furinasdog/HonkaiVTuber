# 无人值守实施与验收计划

每一步先建立可回滚 Git 检查点，完成后通过本步验收再提交并推进。失败留在本步诊断，不把未通过项记为完成。两个应用使用同一版本的共用插件；版权角色素材、视频、识别数据和诊断图片只保存在本机忽略目录。

1. **当前状态备份**：提交已授权的源码、通用材质、许可证和子模块版本；排除已有无关改动与角色素材，核对远程提交。
2. **脸部及清晰度**：使用用户视频离线重放，验证完整/局部眨眼、张嘴、嘴形混合、眼睑部件显隐与关闭恢复。验证窗口 DPI、文字居中、尺寸和裁剪；保持 UI 在输出分辨率绘制。真实 GPU 与非编辑器程序均需验收。
3. **物理稳定性**：基于真实 UE 固定姿态和视频回放验证输入、碰撞与关节，采用通用修复。四模型覆盖静止、运动、动停和重置；记录逐骨帧差、残差与穿透，不以单张截图或原始参考姿态测试代替实际重定向验收。
4. **共享渲染插件**：将材质、着色器及相应运行时控制提取为可复用 UE 插件和独立仓库；两个应用通过 Git 子模块引用。插件不依赖角色、PMX 导入器、动捕或应用 UI。提供使用说明、示例接口和许可证，比较提取前后的相同输入画面。
5. **官方 DLSS 4.5**：核验 NVIDIA 官方 UE 5.8 包及许可后接入；公开仓库只保存允许公开的适配与准备步骤。提供用户开关、硬件检测和关闭恢复，验证实际运行库/模式；DLSS 不代替 UI DPI 修复。
6. **交付**：重新编译、烘焙和打包 Shipping 到新目录，验证启动、窗口模式、用户设置、导入及退出。审计角色资产排除、许可、依赖和校验和；保留旧版本，提交最终版本和依赖引用。

脸部、部件显隐和 DPI 阶段的验证见 `VALIDATION_20261103.md`。固定姿态和前三模型完整回放通过，但识之完整动停尚有残余抖动。物理阶段未放行，详见验证记录；共享插件提取、DLSS 接入及最终新包继续等待本步修复。备份检查点不是完成声明。
